# V4 SIGNATURE SLICE — CINEMATIC STORYBOARD

This slice locks the physics and visual grammar before later chapters inherit them.

## Shot 01 — Recognition (0–2 seconds)

The frame begins almost black. Large material fragments resolve before their full silhouette is understandable. **ADHAM** appears with the retained monumental typography; **MAHMOOD** reads as a quieter architectural layer rather than a duplicate headline.

There is no boot copy, fake status, loading theatre, or technology label.

## Shot 02 — The monument exists (2–8 seconds)

The fragments settle into an enormous incomplete structure that exceeds the viewport. A central aperture carries restrained structural light. Transparent traces of real recent activity occupy depth around it without becoming a graph.

The visitor discovers causality by moving: nearby material yields first, the disturbance travels through adjacent fragments, and the structure returns to equilibrium with weight.

## Shot 03 — Entry (first scroll)

The name does not simply fade above the next section. The monument opens. Its fragments create depth and a passage into NOW. Scroll velocity produces momentary stress and separation; slow travel restores detail.

The emotional transition is recognition → entry, not hero → section.

## Shot 04 — Index revelation

Pressing **I** suspends the current journey. The same fragments visitors have already touched reorganize into five spatial routes. The semantic destinations appear only after the architecture exists:

- NOW
- WORK
- GROWTH / TIME
- HISTORY
- CONTACT

Hover and keyboard focus energize the corresponding physical route. The world is not behind the menu; the world has become the map.

Closing the Index returns the material to the exact current chapter instead of replaying an entrance.

## Shot 05 — Capability manifestations

- **FULL:** rigid fragments, local propagation, transparent Activity Veil, fine matter, depth.
- **REDUCED:** fewer fragments and panes; same silhouette, passage, and Index transformation.
- **STATIC-LOW:** authored SVG monument with central aperture and spatial map state.
- **REDUCED MOTION:** final states replace travel; no meaning is removed.
- **MOBILE:** a portrait monument and thumb-readable vertical Index; no squeezed desktop atlas.

## Signature tests

1. Hide the name: the environment still has a recognizable authored silhouette.
2. Hide the world: the opening materially collapses. If it still feels complete, the world has failed the delete test.
3. Open the Index: the transformation must be visible before the labels become the main event.
4. Move through one local area: only nearby material reacts first.
5. Disable WebGL: the still composition must preserve monument, aperture, construction, and time.
