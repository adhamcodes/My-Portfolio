# V3 Acceptance Checklist

A section may advance only after all applicable checks pass:

- concept is visible without explanation
- visual composition has a unique chapter identity
- Living Trace changes meaningfully, not just position/color
- typography hierarchy is intentional at desktop and mobile widths
- secondary text remains readable at 1080p and common phone sizes
- pointer/touch behavior has a reason and settles naturally
- reduced motion remains premium
- static/WebGL-failure fallback preserves meaning
- keyboard and focus behavior remains correct
- no fabricated activity/progress/metrics
- no console/build/runtime regressions
- production screenshot inspected at desktop and mobile

The final pass repeats the same checks across the entire journey as one continuous experience.
