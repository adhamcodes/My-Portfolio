## Remove or archive after replacement

- old LivingTrace renderer generations not imported by V4;
- the cable/ribbon silhouette as the identity metaphor;
- V3-only CSS overrides once their surfaces have been replaced;
- repeated headline/paragraph/void chapter templates;
- decorative microcopy and technical labels that carry no visitor meaning;
- any sound event that remains imperceptible or arbitrary;
- old V3 visual-certification artifacts from the active product path.

Nothing is deleted merely for cleanliness while a V4 replacement still depends on it. Removal happens after each locked V4 slice passes type, visual, semantic, and reduced-capability checks.

## Build order

1. Freeze doctrine and survival map.
2. Strengthen event truth and build Activity Veil projection.
3. Define the V4 world state contract.
4. Build one vertical slice: Hero → first transformation → Index revelation.
5. Lock the world physics and visual grammar.
6. Re-direct Work, Growth/Time, History, Present, and ZeroUpload through that grammar.
7. Remove superseded V3 visual layers.
8. Certify desktop, mobile, keyboard, reduced motion, reduced hardware, provider failure, and long-session behavior.
9. Present the complete isolated V4 build to Adham. Do not merge before explicit approval.
